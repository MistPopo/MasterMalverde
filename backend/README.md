
# MasterMalverde — Agenda & Catálogo (Full Stack)

## Cómo correr
```bash
cd backend
npm i
npm run seed   # crea DB y datos demo (incluye admin)
npm start
```
El servidor sirve el **frontend** estático en `http://localhost:3000/`
